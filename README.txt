Folders and descriptions
=========================
/conversion scripts/ - contains scripts and source code to perform various conversions.
1) aalekh2uni.exe - converts from CSCD aalekh Devanagari to plain text unicode Devanagari. The batch file aalekh2uni.bat can be used to perform this conversion on all files in the current directory.

2) pitaka2xml.exe - converts from plain text unicode Devanagari to XML Devanagari. The batch file pitaka2xml.bat can be used to perform this conversion on all .txt files in the current directory. No longer used by the site build: the text files are no longer corrected.

DevaMaster2Split.exe - splits the books in /deva master/ into the chapter files of the site, in /tipitaka.org/deva/cscd/. site-build.ps1 runs it.

DevaNormalize.exe - normalizes the text of the books in /deva master/ after they are corrected: en dash, double danda, ellipsis, abbreviation sign, and the ZWJ in conjuncts such as kka and nna. Double-click DevaNormalize.bat to run it on every book. DevaMaster2Split.exe applies the same normalization.

3) deva2*.exe - converts from Devanagari XML to XML of various other scripts 
(Note: script abbreviations are defined by ISO 15924 - http://en.wikipedia.org/wiki/List_of_ISO_15924_codes)

/root text files/ - contains the files generated by aalekh2uni.exe which were then manually modified to apply various corrections. They are no longer corrected; /deva master/ is the only master copy.

/tipitaka.org/ - contains folders for the various scripts which contain CSS, XSL, and JS navigation tree files. The XML in /deva/cscd is an old build: site-build.ps1 replaces it with the split files generated from /deva master/. No other XML is stored in the repository as all others can be generated as needed from the Devanagari XML using deva*.exe.

How to apply corrections to the Tipitaka files
===============================================
1) Apply corrections to the .xml files in /deva master

2) Run /conversion scripts/DevaNormalize.bat to add the ZWJ and the other normalized characters to the corrected text

3) Run site-build.ps1, which splits the books in /deva master into /tipitaka.org/deva/cscd/ with DevaMaster2Split.exe and converts them into the other scripts with the deva2*.exe converters
