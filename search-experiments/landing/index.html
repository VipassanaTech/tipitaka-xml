Tipiṭaka multi-script search — engine bake-off

Three self-hosted prototypes over the same 15-script corpus. Search in any script, read results in two.

Try each engine

Elasticsearch

"flexibility" pick · ES 8 + ICU · ~2–3 GB RAM
  • ICU folding, per-script analyzers
  • exact · wildcard · fuzzy (Damerau)
  • clean path to semantic (dense_vector)
Open ES search →

Typesense

"cost" pick · C++ · ~0.5 GB RAM · ~$5–10/mo
  • built-in typo tolerance, no JVM
  • exact · prefix-wildcard · fuzzy
  • native multi-search fan-out
Open Typesense search →

Apache Solr (current)

production baseline · Solr 3.4 · real prod index
  • single Roman-folded text field
  • exact · wildcard (diacritic-insensitive)
  • no fuzzy, no cross-script fan-out
Open Solr /web →
