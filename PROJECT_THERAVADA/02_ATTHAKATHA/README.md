Aṭṭhakathā — Classical Commentary Layer

Purpose

This directory is reserved for the classical Pāli Aṭṭhakathā layer used in
the Theravāda Research Corpus.

Aṭṭhakathā must remain explicitly distinguished from:

Pāli Mūla / primary textual layer;

Ṭīkā / subcommentarial literature;

later systematic manuals;

modern Theravāda interpretation;

academic reconstruction.

Current stage

INVENTORY ONLY

No .att.xml file should be automatically included in a consolidated
project source merely because its filename ends in .att.xml.

The first task is to identify:

exact work title;

relation to canonical text;

repository family;

file size;

source checksum;

whether the file belongs to the core Aṭṭhakathā corpus or requires review.

Special caution applies to e*.att.xml and any other files outside the
obvious Vinaya / Nikāya / Abhidhamma filename families.
