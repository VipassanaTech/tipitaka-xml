# Theravāda Research Corpus — Source Policy

## Purpose

This document defines how textual authority, repository classification,
canonical status, commentarial interpretation, modern interpretation,
and academic reconstruction are distinguished in this research corpus.

No interpretive layer should silently replace another.

---

## Source hierarchy

The project uses the following analytical hierarchy:

1. Pāli Mūla / primary textual layer
2. Aṭṭhakathā
3. Ṭīkā and later subcommentarial literature
4. Classical systematic Theravāda literature
5. Modern Theravāda traditions and teachers
6. Academic Buddhist Studies
7. Comparative and historical reconstruction

This hierarchy describes textual and interpretive layers.

It does NOT mean that every later source is less useful.
It means that claims must be identified according to their source layer.

---

## Critical distinction

Two separate classifications must always be maintained:

### REPOSITORY_LAYER

How a source is classified inside the VRI/CST repository.

Examples:

- MŪLA
- AṬṬHAKATHĀ
- ṬĪKĀ
- NRF / supplementary

### CANONICAL_STATUS

The status of a work within a particular Theravāda canonical tradition.

REPOSITORY_LAYER must never automatically be treated as identical to
CANONICAL_STATUS.

---

## Mūla rule

The label `MŪLA` in this project primarily records the textual layer
used by the VRI/CST repository.

It does not by itself prove universal canonical acceptance across all
Theravāda regional traditions.

Whenever canonical status varies, the variation must be explicitly recorded.

---

## Variable-status texts

### Milindapañha

Repository layer:

`NRF / supplementary`

Canonical status:

Variable across Theravāda traditions.

It must not be presented as universally canonical.

### Nettippakaraṇa

Repository layer:

`MŪLA` in the VRI/CST navigation used by this corpus.

Canonical status:

Variable across Theravāda traditions.

Its MŪLA repository classification must not be used as proof of universal
canonical status.

### Peṭakopadesa

Repository layer:

`NRF / supplementary`

Canonical status:

Variable across Theravāda traditions.

It must not be presented as universally canonical.

## Canonical text vs commentary

Canonical/root-text material must remain explicitly distinguishable from:

- Aṭṭhakathā;
- Ṭīkā;
- later manuals;
- modern meditation systems;
- modern doctrinal interpretation;
- academic reconstruction.

A commentarial explanation may clarify how the Theravāda tradition
understood a canonical passage, but it must not silently be presented
as wording found in the canonical passage itself.

---

## Commentarial rule

When Aṭṭhakathā or Ṭīkā are used:

1. identify the commentary;
2. identify the canonical passage being interpreted;
3. distinguish direct canonical wording from explanation;
4. record significant differences between canonical text and commentary;
5. avoid retrojecting later terminology into an earlier text without notice.

---

## Modern Theravāda rule

Modern teachers and meditation traditions are valuable sources for
living Theravāda practice.

However, teachings associated with a particular lineage must be labeled
accordingly.

Examples include:

- Mahāsi tradition;
- Pa-Auk tradition;
- Thai Forest traditions;
- Sri Lankan scholastic traditions;
- Burmese Abhidhamma traditions.

A lineage-specific interpretation must not automatically be described
as the position of Theravāda as a whole.

---

## Academic scholarship rule

Academic scholarship may be used for:

- textual history;
- philology;
- chronology;
- comparative Buddhist studies;
- manuscript studies;
- reconstruction of doctrinal development;
- comparison with Sanskrit, Chinese, Tibetan or other witnesses.

Academic reconstruction must remain distinguishable from
traditional Theravāda interpretation.

---

## Translation-control rule

Translations are interpretive witnesses.

When a doctrinal conclusion depends on the meaning of a Pāli term,
the Pāli source should be checked directly whenever practical.

Important terms should be analyzed using:

1. Pāli form;
2. morphology;
3. syntax;
4. immediate canonical context;
5. usage elsewhere in the Canon;
6. Aṭṭhakathā where relevant;
7. Ṭīkā where relevant;
8. Pāli lexicography;
9. modern translations;
10. academic philology where needed.

---

## Claim labeling

For important claims, use one or more of the following conceptual labels:

`CANONICAL`

`COMMENTARIAL`

`SUBCOMMENTARIAL`

`CLASSICAL_SYSTEMATIC`

`MODERN_TRADITION`

`ACADEMIC`

`COMPARATIVE_RECONSTRUCTION`

`INFERENCE`

This is especially important when multiple layers disagree.

---

## Conflict rule

When sources conflict:

1. do not silently harmonize them;
2. identify the conflicting sources;
3. state their textual layers;
4. explain the difference;
5. distinguish what is explicit from what is inferred;
6. preserve uncertainty where the evidence does not resolve the issue.

---

## Provenance rule

Every generated source file must preserve enough metadata to identify:

- original source filename;
- work title;
- textual layer;
- edition;
- provider;
- script;
- source checksum.

---

## Research principle

The project aims to answer four different questions separately:

1. What does the Pāli text say?
2. How does the classical Theravāda commentarial tradition interpret it?
3. How do modern Theravāda traditions apply or explain it?
4. What does modern academic scholarship reconstruct or debate?

These questions must not be collapsed into one another.
