## Attribution

The upstream repository states that its files are made freely available

Vipassana Research Institute when the files are incorporated into projects.

Accordingly, this project attributes the source Pāli textual data to:

**Vipassana Research Institute (VRI)**

The Roman-script Pāli source files used in this research corpus are derived
from the `romn/` XML files of the upstream repository.

---

## Relationship to the source repository

This repository contains a research-processing layer built from the upstream
Tipitaka.org XML corpus.

The project may:

- select source files;
- consolidate multiple source files into research-oriented text files;
- add provenance metadata;
- add source-boundary markers;
- generate manifests and checksums;
- preserve notes and page-reference markers.

These operations do not imply authorship or ownership of the underlying
Pāli textual material.

The underlying source data remain attributed to the
Vipassana Research Institute / Tipitaka.org source corpus.

---

## Textual integrity

The project is designed to preserve the source text while making it easier
to use for research.

Generated files must retain sufficient provenance to identify:

- the original XML filename;
- the work title;
- the textual layer;
- the source edition;
- the source provider;
- the script;
- the source SHA-256 checksum.

No generated research file should silently obscure its relationship
to the original source files.

---

## Updates and synchronization

The upstream repository states that the files are updated from time to time
when errors are discovered and corrected.

For this reason, this project maintains the upstream source repository
separately from the generated Theravāda research corpus and is designed
to allow future synchronization and rebuilding.

Generated corpus versions should record the Git commit used for each build.
