Full Post-Canonical Inventory

This directory contains inventory metadata for the Roman-Pāli XML corpus in
romn/.

It is not a textual source layer and does not consume a project source slot.

The inventory separates:

the 61 XML inputs already assigned to the validated Pāli Canon v1.0.0;

all remaining Roman XML files;

files requiring manual bibliographic review.

Critical rule

Repository suffixes are not treated as final scholarly classifications.

Examples:

.mul.xml does not automatically mean universally canonical;

.att.xml does not automatically prove that the work is an Aṭṭhakathā to a canonical text;

.tik.xml does not remove the need to identify the exact Ṭīkā;

.nrf.xml is a repository category and requires work-level identification;

e*.xml files require explicit review.
